# TIMO MOD Package Repository

This repository contains the package sources and metadata for TIMO MOD.

## Structure

```
timomod-repo/
├── sources.json                    # Main sources file
├── repositories/
│   └── official/
│       └── repo.json              # Official repository metadata
├── packages/                      # .timo patch files
├── wallpapers/                    # .tendies wallpaper files  
└── icons/                         # Package icons
```

## Adding Your Repository

To add this repository to TIMO MOD:

1. Open TIMO MOD
2. Go to Repository tab
3. Tap "+" to add source
4. Enter: `https://raw.githubusercontent.com/timomod/timomod-repo/main/sources.json`

## Package Format

Packages use `.timo` extension (rebranded from `.3105`)

## Wallpapers

Wallpapers use `.tendies` format for compatibility.
